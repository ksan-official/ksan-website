# 가입·인증·활동 정책

사용자 확정 사항을 기준으로 한 개발 전달 문서. 현재 작업은 화면 시제품이며 아래 권한 정책을 서버에서 구현한 상태는 아니다.

## 가입과 신분 인증

- 일반 이메일로 간단 가입한다. 학교 이메일을 가입 조건으로 요구하지 않는다.
- 가입 필수 항목: 닉네임, 일반 이메일, 비밀번호. 이름·학교·전공·입학연도는 가입 시 요구하지 않는다. 로컬의 입력 없이 진행하는 동작은 유지한다.
- 닉네임은 활동용 공개 이름이다. 이름과 학교 관련 정보는 가입 후 신분 인증 단계에서 받는다. 이름은 관리자만 확인하며 다른 사용자에게 공개하지 않는다.
- 가입 후 신분 인증 단계에서 재학생·입학예정자·졸업생을 선택한다.
- 재학생: 학교 이메일 인증. 인증 전에는 학교 소속을 확정하지 않는다.
- 입학예정자: 입학허가서 제출 후 관리자 수동 인증.
- 졸업생: 졸업증명서 제출 후 관리자 수동 인증.
- 인증 전에는 ‘미인증’, 요청 후에는 ‘확인 대기’, 인증 완료 후에는 동일한 Verified 배지를 표시한다. 재학생·입학예정자·졸업생 구분은 인증 방식에 사용하며 공개 배지 유형을 나누지 않는다. 단순 신분 선택이나 서류 제출을 인증 완료로 표시하지 않는다.
- 가입 후 인증 안내에서는 닉네임 옆에 주황색 인증 인장 형태와 흰 체크로 된 Verified 배지의 인증 후 모습을 보여준다. 실제 인증 상태는 별도로 유지하며 시연용 안내 문구는 노출하지 않는다. 내부 동작은 계속 시제품으로, 실제 계정 생성·메일 발송·파일 업로드·인증 처리는 하지 않는다.

## 비회원 권한

| 항목 | 비회원 |
| --- | --- |
| 정착가이드 | 일부만 열람 가능 |
| 중고거래 게시글 | 열람 가능 |
| 댓글 내용 | 열람 불가 |
| 댓글 작성 | 불가 |
| 좋아요 | 불가 |
| 거래 참여 | 불가 |

- 제한 지점에는 로그인·가입 안내를 제공한다. 비회원에게 댓글 본문을 내려준 뒤 CSS로 가리는 방식으로 구현하지 않는다.
- 미인증 회원과 인증 회원 간 활동 권한 차이는 아직 미정이다. 비회원 제한을 미인증 회원에게 자동 적용하지 않는다.
- 정착가이드의 공개 대상 문서/구간과 그 밖의 메뉴에 대한 비회원 접근 범위는 별도 확정이 필요하다.

## 공개 이름과 실명

- 글·댓글·좋아요·중고거래를 포함한 모든 활동의 공개 이름은 닉네임이다.
- 실명은 관리자에게만 노출한다. 공개 API·게시글·판매자 정보·댓글·거래 상대방 정보에 실명을 포함하지 않는다.
- 기존 `full_name`을 공개 이름의 대체값으로 사용하지 않는다. 닉네임이 없으면 닉네임 설정을 안내한다.
- 실명을 공개 프로필과 분리하고 관리자 권한으로 조회를 제한한다. 인증 서류도 공개 URL로 제공하지 않는다.
- 신분·인증 완료 상태는 서버의 검증 결과로 결정한다. 클라이언트나 사용자가 수정 가능한 메타데이터로 신뢰하지 않는다.

## 개발 연결 범위

- 현재 `/auth`는 일반 이메일 가입 → 미인증 → 신분별 인증 입력 → 확인 대기 흐름의 화면 시제품이다.
- 기존 프로필·DB·관리자 화면에는 새 닉네임/인증 모델과 공개 정보 분리가 아직 반영되지 않았다. 인증 정보 저장과 비회원 권한 제한은 실제 개발 시 구현한다.
- 서버 권한 검사, 학교 이메일 소유 확인과 학교 도메인 판별, 서류 심사·보완 요청, 승인·반려 알림, 닉네임 중복 처리, 인증 자료 보관·삭제 기준을 연결해야 한다. 세부 정책은 확정 후 구현한다.

## 로컬 화면 둘러보기

- 별도의 화면 목록과 이동 도구를 제공하지 않는다. 로컬에서는 기존 로그인 버튼을 누르면 입력 없이 마이페이지로 이동한다. 가입·인증·비밀번호 재설정도 입력 없이 다음 화면으로 진행할 수 있다.
- 프로필 화면의 신분 인증하기를 누르면 `/auth/verify`로 이동한다.
- 개발 환경의 마이페이지는 로그인 세션 대신 가상의 회원·활동 기록을 사용한다. 프로필 수정은 현재 화면의 상태에만 적용한다. 실제 회원 데이터와 API 권한 검사는 변경하지 않는다.
- 입력 없이 진행하는 동작과 가상의 회원 데이터는 `NODE_ENV=development`에서만 활성화된다. 운영 환경의 실제 인증·API 권한 검사는 유지한다.
- 관리자 화면은 이 둘러보기 범위에 포함하지 않는다.
