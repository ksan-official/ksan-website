# 로그인 화면 전달 사항

- 경로: `/auth`
- 기준: 사용자 제공 에브리타임 로그인 이미지. 흰 배경, 중앙 단일 열, 연회색 입력창, 넓은 여백을 유지하고 KSAN 로고와 주황색을 적용한다.
- 로그인: 이메일을 아이디로 사용하며 비밀번호 입력, 로그인 유지, 계정 찾기, 회원가입 진입을 제공한다.
- 회원가입: 닉네임·일반 이메일·비밀번호를 받는다. 이름과 학교는 가입 시 받지 않으며, 가입 후 선택적으로 신분 인증을 진행한다. 정책은 `membership-policy.md`를 따른다.
- 비밀번호 재설정: 계정 찾기 → 이메일 입력 → 이메일 확인 안내 → 재설정 화면 미리보기 → 새 비밀번호·확인 입력 → 변경 완료 → 로그인 흐름을 시연한다. 최소 8자와 비밀번호 일치를 검증한다. 이메일 발송과 실제 비밀번호 변경은 하지 않는다.
- 실제 개발 시 이메일 재설정 링크, 만료·유효하지 않은 링크 안내, 인증된 복구 세션 검증, 비밀번호 변경 API와 성공·실패 처리를 연결한다. 실제 개발에서는 메일의 인증된 링크로 재설정 화면에 진입하도록 연결한다.
- 로그인 유지 체크박스는 화면 시연용이다. 기존 인증 클라이언트는 체크 여부와 무관하게 세션을 유지하므로 실제 구현 시 체크 상태와 세션 보관 정책을 연결해야 한다.
- 로그인 제출은 기존 Supabase 연동을 유지한다. 회원가입은 실제 계정을 생성하지 않고 미인증·신분 인증·확인 대기 화면을 시연한다. 실제 로그인 없이 가입 흐름을 검토할 수 있다.
- 이용약관·개인정보처리방침은 안내 메시지만 제공한다. 확정 문서로 연결해야 한다. 문의하기는 소개 페이지의 문의 영역으로 연결한다.
- 로고를 누르면 홈으로 돌아간다. 화면은 모바일 폭에 맞춰 줄어들고 모든 필드에 접근 가능한 이름과 키보드 포커스를 제공한다.
- 두 번째 Braintrust 이미지는 향후 마이페이지 저장 목록 구성 참고로 보류한다. 이번 변경에는 포함하지 않는다.

## 디자인 검토용 케이숲·중고거래 동작

- 이 저장소는 개발자 전달용 디자인 시안이다. 기본값으로 로컬과 배포 빌드 모두 `/community`, `/pass-it-on`의 게시판과 상품 목록, 마이페이지의 가상 프로필, 채용 샘플을 동일하게 표시한다.
- 실제 서비스 연동 화면으로 전환하려면 빌드 전에 `NEXT_PUBLIC_KSAN_DESIGN_MODE=false`를 설정한다. 브라우저 코드에도 포함되는 값이므로 변경 후 재빌드해야 한다.
- 케이숲: 카테고리·검색, 글 등록, 상세 열기, 댓글, 좋아요, 저장. 마이페이지에서 내 글·내 댓글·저장한 글을 확인한다.
- 중고거래: 카테고리·검색, 상품 등록(이미지 1장, 2MB 이하), 상세 열기, 저장, 판매자 문의 작성, 내 상품 거래 완료 전환. 마이페이지에 내 판매·저장한 상품·문의 내역을 연결한다.
- 데이터와 문의 메시지는 현재 브라우저의 localStorage에만 저장한다. 서버 게시, 실제 상대방 전송, 결제, 실시간 채팅은 연결하지 않았다. 브라우저 저장공간이 부족하면 현재 세션에만 반영된다.
- 디자인 검토 모드는 로그인 없이 가상 데이터와 브라우저 저장 데이터를 검토하기 위한 동작이다. 실제 인증 세션, 관리자 권한, 서버의 접근 정책은 변경하지 않는다.
- 채용 카드는 회사·제목·지역·고용형태·공고 보기만 두며, 분류 배지·키워드 태그·상세 펼치기는 제거했다.

- 마이페이지의 채용·행사·가이드·케이숲·중고거래 항목은 카드나 행을 누르면 해당 상세 페이지로 이동한다. 케이숲과 중고거래 상세는 팝업 대신 `/community/[id]`, `/pass-it-on/[id]` 주소를 사용한다. 내 댓글은 댓글 영역, 문의 내역은 상품의 문의 영역으로 바로 연결한다.
